# EAWAG DATASET README TEMPLATE v2

# Why this format: the file stays readable in any text editor, but follows a
# grammar strict enough that software can parse it. That gets you most of the
# way to "Interoperable" without asking anyone to hand-edit XML.
#
# GRAMMAR
#   Section headings   ALL CAPS, alone on a line.
#   Fields             "Field name: value" (one colon, value may be empty).
#   Long values        continuation lines indented by exactly two spaces.
#   Lists              lines starting with "- " under a field.
#   Repeated blocks    separated by a blank line (e.g. one per author).
#   Comments           lines starting with "#" (stripped by parsers).
#   Dates              ISO 8601, YYYY-MM-DD. Ranges as YYYY-MM-DD/YYYY-MM-DD.
#   Unknown values     write [CONFIRM] rather than guessing or leaving blank.
#                      A blank means "not applicable"; [CONFIRM] means "we
#                      still owe someone an answer". The distinction matters
#                      when someone picks this up in three years.
#
# Fields marked [ON PUBLICATION] can stay empty while a dataset is internal.
# Fill them before any external release. Everything else should be filled.
